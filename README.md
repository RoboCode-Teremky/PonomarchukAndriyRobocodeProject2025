# Robocode Project 2025

Дана гра є проєктом розробленим спеціально для конкурсу [Robocode Project 2025](https://project.robocode.ua/). Проєкт виконано згідно [вимог конкурсу](https://docs.google.com/document/d/1q4BinM9vw-rsBU84oSi-SiLKpE0YCGdrhTRXYSjRDLQ/edit?tab=t.0)

# Опис

- Назва: Castle Defense
- Тематика: Фінансова грамотність
- Жанр: Tower Defense
- Автор: Пономарчук Андрій
- Сетинг: середньовіччя

Захищай свою базу за допомогою різних захисних споруд. Будуй свою економіку. У грі є валюта, яку гравець може витрачати на купівлю споруд оборонного призначення. Валюта заробляється за рахунок ліквідації ворогів, за кожну пройдену хвилю. Вороги йдуть до бази гравця по вже визначених доріжках.

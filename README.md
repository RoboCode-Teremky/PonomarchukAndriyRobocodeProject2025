- Тематика: Фінансова грамотність

Захищай свою базу за допомогою різних захисних споруд. Будуй свою економіку. У грі є валюта, яку гравець може витрачати на купівлю споруд різного призначення (як оборонні так і промислові). Валюта заробляється за рахунок ліквідації ворогів, за кожну пройдену хвилю та з промислових споруд. Вороги йдуть до бази гравця по вже визначених доріжках. Планується зробити декілька мап з різними рівнями складності.
